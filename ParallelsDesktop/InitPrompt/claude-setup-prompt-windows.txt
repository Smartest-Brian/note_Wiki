【給 Claude 的初始設定 prompt】(Windows 版)
請依照以下規格，在這台 Windows 電腦上建立完整的工作目錄與規則檔案。
帳號路徑請一律使用 C:\Users\{account}\，{account} 請替換為當前 Windows 使用者帳號名稱。

================================================================
一、基本原則
================================================================
1. 工作目錄位置：C:\Users\{account}\claude-workspace\
2. 不導入 Git 版本控制。
3. 操作日誌格式採用 JSONL（activity_log.jsonl）。
   理由：append 不會破壞格式、可用 jq 或程式查詢統計；
         人眼閱讀需求由 memory/*.md 的整理表格滿足。
4. 目錄配置原則：
   - data/ 與 logs/ 放在 .claude/ 之外（workspace 根層），
     .claude/ 只放「給 AI 的指示與記憶」。
   - activity_log 放進 logs/，支援每月封存至 logs/archive/。
   - 不設 data/dev/，開發資料放各專案自身路徑，由 memory/dev.md 索引。
   - 另建立 data/general/ 與 README.md。
   - 另建立 .claude/wrappers/，專門存放「密鑰存取用的 wrapper script」，
     此資料夾內只放腳本本身，不放任何明文密鑰。

# Workspace 主規則檔

本檔只放：全域規則、任務分類索引、資料路徑索引。
任何分類的細節內容一律寫入 memory/ 對應子檔案，不得堆積於此。

## 一、全域行為準則

### 語言
- 對話回覆一律使用繁體中文。
- 程式碼中的註解一律使用英文。
- 本檔與所有 memory 子檔案以繁體中文撰寫。

### 紀錄義務
每次執行涉及「資料存取 / 修改 / 下載」的操作，完成後必須：
1. 判斷分類：股票 / 網路 / 開發 / 其他。
2. 將細節（做法、參數、結論、觀察）寫入對應 memory 子檔案。
3. 於 logs/activity_log.jsonl 追加一行紀錄（格式見第四節）。
4. 若產生實際資料檔，存入 data/ 對應子資料夾，並於該 memory 子檔案的
   「資料檔索引」註明完整路徑。

activity log 只記「何時、哪個分類、做了什麼」，不寫分析細節。

### 密鑰 / Token 存取
任何操作需要用到密鑰、Token、API Key（例如呼叫外部 API、啟動 MCP server）時：
1. 先檢查 `.claude\wrappers\` 底下是否存在對應的 wrapper script
   （命名規則見「五、Token 安全儲存機制」）。
2. 若存在：直接呼叫該 wrapper script 取得對應環境變數並使用，
   **不得**自行嘗試讀取 Windows 憑證管理員原始資料、不得要求使用者貼上明文。
3. 若不存在：停止操作並告知使用者「尚未設定此密鑰的 wrapper script」，
   引導使用者依「五、Token 安全儲存機制」章節建立，
   **不得**主動詢問使用者要不要直接把明文 token 貼在對話或檔案中。
4. 任何情況下，取得的 token / 密鑰明文都不得寫入 activity_log.jsonl、
   memory/*.md、data/ 底下任何檔案，或出現在回覆內容中。

### 安全
- 不在任何檔案（含 log 與 memory）中寫入密碼、API key、憑證、個資。
- 破壞性操作（刪除、覆寫、格式化）或對外操作（上傳、送出、發佈）前，
  先向使用者確認。
- 覆寫或刪除前先檢視目標內容。

### 時間格式
- 一律使用 ISO 8601 含時區，時區為 +08:00。
  例：2026-08-29T14:30:00+08:00

## 四、activity_log.jsonl 每行格式

每行為一個獨立 JSON 物件（JSONL），欄位如下：

    {"ts":"2026-08-29T14:30:00+08:00","category":"stocks","action":"download","summary":"下載台積電近一年日K CSV","files":["data/stocks/2026-08-29_2330_daily.csv"],"memory":"memory/stocks.md"}

- ts：ISO 8601 含 +08:00 時區。
- category：stocks | network | dev | general。
- action：read | write | download | delete | analyze | other。
- summary：一句話摘要。
- files：本次產生或修改的資料檔，路徑相對 workspace 根目錄；無則空陣列 []。
- memory：本次細節寫入的 memory 子檔案路徑。

### 每月封存規則
每月首次寫入前，若 activity_log.jsonl 內含上個月（或更早）的紀錄，
先將既有內容整檔搬到 logs/archive/YYYY-MM.jsonl（依當前紀錄多數所屬月份命名），
再清空 activity_log.jsonl 並寫入本月新紀錄。

## 五、Token 安全儲存機制（Windows：憑證管理員）

Windows 沒有 macOS Keychain 的 `security` 指令，對應的替代方案是
**Windows 憑證管理員（Credential Manager）**，透過 PowerShell 的
`CredentialManager` 模組存取（比原生 `cmdkey` 更適合，因為
`cmdkey` 存入的密碼無法用腳本讀回明文，`CredentialManager` 模組可以）。

### 5.1 安裝模組（僅需一次）
```powershell
Install-Module -Name CredentialManager -Scope CurrentUser -Force
```

### 5.2 存入密鑰（使用者手動執行，不由 Claude 自動執行）
```powershell
New-StoredCredential -Target "LINE_CHANNEL_ACCESS_TOKEN" -UserName $env:USERNAME -Password "你的token" -Persist LocalMachine
New-StoredCredential -Target "LINE_USER_ID" -UserName $env:USERNAME -Password "你的id" -Persist LocalMachine
```

### 5.3 wrapper script 命名與存放規則
- 存放路徑固定為：`C:\Users\{account}\claude-workspace\.claude\wrappers\`
- 命名規則：`start-{用途}.ps1`，例如 `start-line-bot.ps1`
- wrapper script 只負責「從憑證管理員取值 → export 成環境變數 → 呼叫實際程式」，
  本身不得包含任何明文密鑰。

### 5.4 wrapper script 範例
```powershell
# .claude\wrappers\start-line-bot.ps1
$token = (Get-StoredCredential -Target "LINE_CHANNEL_ACCESS_TOKEN").GetNetworkCredential().Password
$userId = (Get-StoredCredential -Target "LINE_USER_ID").GetNetworkCredential().Password

if (-not $token -or -not $userId) {
    Write-Error "無法從憑證管理員讀取必要密鑰"
    exit 1
}

$env:LINE_CHANNEL_ACCESS_TOKEN = $token
$env:LINE_USER_ID = $userId

# 呼叫實際程式，例如：
node "C:\path\to\your\line-bot-server\index.js"
```

### 5.5 若情境涉及 Claude Desktop（非 Claude Code）的 MCP 設定
如果這台機器上另外也有安裝 Claude Desktop、且要串接 MCP server，
密鑰配置檔位置為：

```
%APPDATA%\Claude\claude_desktop_config.json
```

規則同樣是：**不要**在該 JSON 的 `"env"` 欄位直接寫明文 token，
而是把 `"command"` 指向上述 wrapper script（`.ps1` 需搭配
`powershell -File` 呼叫），讓 Claude Desktop 啟動 MCP server 時
透過 wrapper 動態注入環境變數。範例：

```json
{
  "mcpServers": {
    "line-bot": {
      "command": "powershell",
      "args": ["-ExecutionPolicy", "Bypass", "-File", "C:\\Users\\{account}\\claude-workspace\\.claude\\wrappers\\start-line-bot.ps1"]
    }
  }
}
```

此章節屬於「知識參考」，Claude 不得自動修改 `claude_desktop_config.json`，
如需變更須先向使用者確認。

# claude-workspace

Claude Code（/remote-control）在這台 Windows VM 上的行為紀錄與分類機制。

## 導覽
- `.claude/CLAUDE.md` — 主規則檔（全域規則、分類索引、路徑索引、Token 存取機制）
- `.claude/wrappers/` — 密鑰存取用 wrapper script（不含任何明文密鑰）
- `.claude/memory/` — 各分類細節紀錄
  - `stocks.md` 股票 / 市場分析
  - `network.md` 網路偵測與診斷
  - `dev.md` 程式開發
  - `general.md` 其他雜項
- `data/` — 實際產生的資料檔（stocks / network / general）
- `logs/activity_log.jsonl` — 按時間累積的操作日誌（append-only，當月）
- `logs/archive/` — 每月封存的舊日誌

## 運作方式
`C:\Users\{account}\.claude\CLAUDE.md` 內以 `@import` 指向本資料夾的
`.claude/CLAUDE.md`，因此不論 Claude Code 的工作目錄在哪，規則都會生效。

密鑰一律不落地於本資料夾內任何檔案，只存於 Windows 憑證管理員，
由 `.claude/wrappers/` 內的腳本在執行當下動態取用。
